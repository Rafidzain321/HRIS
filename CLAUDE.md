# Communication

- Selalu jawab dalam Bahasa Indonesia.
- Code, command, nama file, nama class, method, variable, dan pesan error tetap menggunakan bahasa aslinya.
- Berikan penjelasan secara ringkas dan jelas.

# Development Rules

- Jangan mengubah file di luar scope tanpa alasan yang jelas. kalau ingin mengubah tanyakan terlebih dahulu
- Hindari membuat method atau abstraction tambahan jika tidak diperlukan.
- Periksa perubahan yang sudah ada sebelum mengedit.
- Jalankan lint dan build satu kali setelah seluruh perubahan selesai.
- Jangan menjalankan migration, menghapus file, atau mengubah Git history tanpa izin.
